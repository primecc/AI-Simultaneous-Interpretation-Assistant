# 开发路线图

## PR 1：初始化项目结构与基础服务

- 搭建 Python 项目结构。
- 配置依赖、测试和代码质量工具。
- 搭建 FastAPI 服务。
- 增加基础 README。
- 提供可连接的前端页面。

## PR 2：实现实时字幕核心模型

- 定义字幕片段状态。
- 支持 `partial`、`final`、`corrected`。
- 使用 `segment_id` 和 `revision` 支持自动修正。
- 补充字幕修正单元测试。

## PR 3：实现本地同传流水线

- 提供无需 API key 的本地识别与中文翻译字幕流。
- 通过 WebSocket 推送字幕更新。
- 展示识别错误被后续修正的过程。

## PR 4：支持字幕导出

- 支持 TXT 导出。
- 支持 SRT 导出。
- 补充导出单元测试。

## PR 5：接入真实音频与 AI 能力

- 接入本地麦克风或系统音频采集。
- 增加 VAD 与音频切片。
- 接入 ASR。
- 接入中文翻译。

## PR 6：完善演示与提交材料

- README 补全依赖、原创功能、启动方式和 demo 链接。
- 准备演示脚本。
- 录制并上传 demo 视频。
