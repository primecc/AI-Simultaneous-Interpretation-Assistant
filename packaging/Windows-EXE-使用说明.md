# AI 同声传译助手 Windows EXE 使用说明

## 启动

双击运行：

```text
AI-Simultaneous-Interpreter.exe
```

软件启动后，屏幕上会出现一个可拖动的“译”悬浮图标。

## 网页/软件后台翻译

1. 打开 exe。
2. 打开哔哩哔哩、网课、会议网页或任意播放英文声音的软件。
3. 点击屏幕上的“译”图标。
4. 程序会直接读取电脑正在播放的声音，并在屏幕底部显示中文字幕。
5. 再点击一次“译”图标即可关闭字幕。

不需要填写 OpenAI API key，也不需要安装浏览器扩展。首次运行会自动准备本地识别模型；翻译使用免 key 在线翻译通道，因此需要网络可用。

右键“译”图标可以打开完整软件界面或退出程序。

## 导入视频/音频生成字幕

打开完整软件界面：

```text
http://127.0.0.1:8000
```

选择本地视频或音频文件，点击“播放并生成字幕”。字幕会显示在播放器上方，并同步保留到历史记录中，可导出为 TXT 或 SRT。

## 当前能力

- Windows EXE 启动器
- 桌面可拖动“译”悬浮开关
- 系统音频读取，支持网页和软件播放声音
- 本地语音识别
- 免 key 中文翻译
- 桌面字幕浮层
- 视频/音频导入字幕
- 软件内播放器字幕覆盖层
- 字幕历史记录
- TXT/SRT 导出
